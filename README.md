# Print Resolution Calculator

Локальный офлайн-калькулятор для подготовки растровых изображений к печати:
расчёт требуемого разрешения (px) под заданный формат и PPI, фактического PPI
исходника, коэффициента апскейла и итогового размера — с проверкой
соотношения сторон.

Работает как обычный `.html`-файл в браузере **или** как отдельное Windows
desktop-приложение (`.exe`) — это один и тот же интерфейс и логика, второй
вариант — просто обёртка в нативное окно.

## Скачать готовый .exe

Собранный `PrintResolutionCalculator.exe` не хранится в репозитории —
берите последнюю версию на странице **[Releases](../../releases)**.
Ничего устанавливать не нужно: один файл, офлайн, без Python.

Если релизов ещё нет (или хотите свежую сборку из текущего кода) — соберите
сами, см. ниже, или запустите workflow вручную во вкладке **Actions**.

## Запуск без сборки

Проще всего — просто открыть `print-resolution-calculator.html` в любом
браузере. Это тот же интерфейс, что и в `.exe`, без установки чего-либо.

## Сборка .exe самостоятельно

Нужна Windows-машина с Python 3.9+.

```bat
git clone <URL-этого-репозитория>
cd <папка-репозитория>
build_exe.bat
```

Готовый файл появится в `dist\PrintResolutionCalculator.exe`.

## Автосборка через GitHub Actions

В репозитории настроен workflow (`.github/workflows/build-release.yml`),
который сам собирает `.exe` на виртуальной Windows-машине и прикрепляет его
к релизу. Чтобы выпустить новую версию:

```bash
git tag v1.0.0
git push origin v1.0.0
```

После этого зайдите во вкладку **Actions** — там будет видно ход сборки,
а по завершении exe появится в **Releases** автоматически. Можно также
запустить сборку вручную (без тега) через Actions → *Build and release
Windows exe* → *Run workflow* — файл ляжет в артефакты запуска.

## Структура репозитория

```
print-resolution-calculator.html   — интерфейс и вся логика расчётов
main.py                            — обёртка в нативное окно (pywebview)
requirements.txt                   — зависимости для сборки
build_exe.bat                      — локальная сборка одной командой
.github/workflows/build-release.yml — автосборка и публикация в Releases
```

## Правки калькулятора

Меняйте только `print-resolution-calculator.html` — это единственный файл
с логикой. `main.py` его не модифицирует, просто открывает в окне.
